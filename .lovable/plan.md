# The Beauty Bar Salon & Academy website

## Build
- Create a polished one-page salon and academy website using the supplied logo and salon interior photo.
- Use a champagne-luxury editorial design: warm ivory, espresso, muted rose, and restrained gold accents.
- Add a transparent-to-solid header, immersive photo-led opening, editorial About section, interactive service categories, Academy feature, real-photo gallery, location/contact content, and a premium footer.
- Add working phone, WhatsApp, directions, navigation, lightbox, mobile menu, and mobile action bar.
- Build a five-step appointment request flow that gathers service, future date, preferred time, and customer details, then prepares a WhatsApp confirmation without claiming live availability.
- Add accessible motion, reduced-motion support, mobile-first layouts, local-search metadata, and structured business data.

## Content safeguards
- Use only the supplied business details and photographs.
- Do not invent prices, opening hours, reviews, qualifications, statistics, certifications, or real-time availability.

## Technical details
- Store uploaded images through the project asset service and import their asset pointers.
- Keep the experience frontend-only; appointment requests finish through WhatsApp or phone, so no saved booking database is implied.
- Extend the existing semantic design tokens and reusable controls rather than adding isolated styling.
